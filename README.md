# Conecta-UFOP

O Conecta UFOP é uma plataforma web de caronas voltada para a comunidade acadêmica da Universidade Federal de Ouro Preto. O sistema conecta motoristas e passageiros que desejam compartilhar trajetos entre os campi e cidades vizinhas (como Ouro Preto, Mariana e João Monlevade).
O objetivo é facilitar o transporte entre estudantes e servidores, reduzir custos e incentivar a mobilidade sustentável dentro da universidade.
